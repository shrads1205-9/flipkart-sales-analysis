#  Flipkart Sales Data Analysis

This project focuses on analyzing Flipkart sales data to understand customer purchasing behavior, product performance, and overall sales trends. The analysis helps in identifying key factors that influence revenue and customer satisfaction.


# Tools & Technologies Used
- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  



# Dataset Description
The dataset contains information about Flipkart sales including:
- Order ID  
- Product Name  
- Category  
- Price (INR)  
- Quantity Sold  
- Total Sales (INR)  
- Order Date  
- Payment Method  
- Customer Rating  



#Analysis Performed
- Category-wise Sales Analysis  
- Top Selling Products  
- Price vs Sales Relationship  
- Quantity vs Sales Analysis  
- Monthly Sales Trend  
- Payment Method Analysis  
- Customer Rating Analysis  



# Machine Learning Model
A **Linear Regression model** is used to predict total sales based on the quantity sold.

# Key Insights
- A few products contribute to most of the total sales  
- Certain categories dominate revenue generation  
- Higher quantity leads to higher sales  
- Sales vary across months indicating seasonal trends  
- Customers prefer specific payment methods  
- Most customer ratings are positive  

# Conclusion
This project demonstrates how data analytics can be used to extract meaningful insights from e-commerce data. The findings help businesses make better decisions, improve sales strategies, and enhance customer experience.
